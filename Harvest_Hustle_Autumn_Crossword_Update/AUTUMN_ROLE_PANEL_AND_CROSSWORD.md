# Autumn role panel and crossword coins

Run `/harvest role-panel` as a configured host to refresh the existing panel in the same event channel. The button continues to toggle the existing event role.

Use `/harvest adjust-coins member:@Player amount:200 reason:Crossword - 8 correct words` to award 200 in-game coins (25 per word). Negative amounts remove coins. Host-only, ephemeral, registered players only, farming must be active, no negative balances; all changes appear in `/harvest history` and the leaderboard.

The bot still includes the previously configured final-score upgrade resale credits; this update does not alter game economics.
