# Version 3 — planting-only actions

- 10 planting actions every 12-hour session (140 possible across 14 sessions).
- Eight starting plots; up to four extra plots via upgrades.
- Harvest, sell and upgrades do not consume planting actions.
- Crop prices unchanged from high-reward version.
- Upgrade prices: extra plot 1,000 coins (resale 500); market stall 1,700 coins (resale 848), +10% sales per level.
- Registration, leaderboard, objectives, stats, host dashboard and notices retained.
